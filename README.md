# NetCanvas

> Draw your network. NetCanvas does the rest.

NetCanvas is a visual, intent-driven network configuration platform.

Instead of configuring routers, switches, access points, VLANs, ACLs, and firewall rules directly, users design the network they want using an intuitive drag-and-drop canvas. NetCanvas translates that design into platform-specific configurations for supported networking ecosystems.

## Vision

Traditional network management software is device-centric.

NetCanvas is network-centric.

Rather than asking:

- "Which switch port?"
- "Which ACL?"
- "Which VLAN?"
- "Which DHCP scope?"

NetCanvas asks:

> "What are you trying to accomplish?"

The resulting design becomes the single source of truth for the network.

## Core Philosophy

- Draw the network.
- Preview the changes.
- Deploy safely.
- Learn only when you want to.

NetCanvas should never require networking expertise.

But it should always reward curiosity.

## Design Goals

- Visual drag-and-drop configuration
- Vendor-independent architecture
- Secure-by-default recommendations
- Explainable configuration
- Deterministic deployments
- Infrastructure as Code concepts without requiring code
- Automatic documentation
- Extensible platform drivers

## Project Status

NetCanvas is currently in the architecture and design phase.

The goal is to create a new generation of network configuration software that makes professional networking accessible without hiding its power.
